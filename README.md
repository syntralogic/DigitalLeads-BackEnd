# DigitalLeads Backend API

Enterprise affiliate tracking platform with PostgreSQL and Redis.

## 🚀 Features

- **Authentication & Authorization** - JWT-based auth with role-based access
- **Network Management** - Full CRUD for affiliate networks
- **Offer Management** - Complete offer lifecycle management
- **Click Tracking** - Real-time click tracking with fraud detection
- **Conversion Tracking** - Conversion status management
- **Analytics** - Advanced reporting with multiple dimensions
- **Fraud Detection** - Automated fraud detection and prevention
- **Smart Routing** - Rule-based traffic routing
- **Postback System** - Global, network, and offer postbacks
- **Domain Management** - Track and manage domains
- **Notifications** - Real-time alerts and notifications
- **AI Dashboard** - AI-powered insights and recommendations
- **Audit Logs** - Complete audit trail

## 🛠️ Tech Stack

- **Node.js** - Runtime environment
- **Express.js** - Web framework
- **TypeScript** - Type safety
- **PostgreSQL** - Primary database
- **Prisma** - ORM
- **Redis** - Caching and queues
- **Bull** - Job queue processing
- **Winston** - Logging
- **JWT** - Authentication
- **Docker** - Containerization
